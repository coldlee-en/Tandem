Before you start

Use a Mac with Xcode 26 or later, XcodeGen, Python 3, and Git. The native Switch build also needs .NET 8 and Git LFS. The build scripts prepare pinned graphics headers and native source dependencies.

An unsigned native development IPA is available. The successful Actions artifact includes the IPA, manifest, and checksum. Re-sign the app and embedded native code before sideloading; Switch requires JIT. Physical-device execution, game compatibility, and performance remain unverified.

Get the unsigned development IPA from Actions ↗. GitHub sign-in may be required, and the temporary artifact is subject to retention limits. There is no GitHub Release. To build from source, clone the repository and run the commands below from its root.

01 / Build the interface

The standard project supports the library and controls without emulator binaries. Settings reports unavailable cores, and gameplay cannot start until native cores are embedded.

xcodegen generate
open Tandem.xcodeproj

Select the Tandem scheme and an installed iOS simulator or device. For a physical device, choose your own development team and a unique bundle identifier.

02 / Compile an unsigned IPA

The native build command prepares both cores, generates the Xcode project, archives for a physical iOS device, and packages an IPA only after a successful compiler and linker run.

bash scripts/build_ipa.sh --native

A successful build writes dist/ipa/Tandem-native-unsigned.ipa, a manifest, and a checksum. The app and every embedded native binary must be re-signed for your device before installation. Packaging an unsigned IPA does not grant JIT.

You can also run the repository’s Build unsigned IPA GitHub Actions workflow on its macOS runner. Select native for both cores; interface explicitly contains no emulator binaries. An artifact appears only if the build succeeds.

Prepare individual cores

For an interactive Xcode build, prepare the pinned Folium/Cytrus source and checked patches, then generate the native project. Graphics headers are prepared by the setup script; TANDEM_VULKAN_INCLUDE can override their location.

bash scripts/prepare_3ds.sh
export TANDEM_VULKAN_INCLUDE="$PWD/Vendor/GraphicsHeaders/include"
python3 scripts/generate_native_project.py --3ds --generate
open TandemNative.xcodeproj

The generator checks for Vulkan, glslang, and Vulkan Memory Allocator headers. Swift Package Manager restores additional native dependencies. See the repository guide if your SDK uses different header locations.

Nintendo Switch · MeloNX

Build the pinned MeloNX NativeAOT core on the Mac, then generate the project that embeds it. The detailed Switch guide documents .NET, native artifacts, and dependencies.

bash scripts/build_switch.sh
python3 scripts/generate_native_project.py --switch --generate
open TandemNative.xcodeproj

For both systems, run both preparation scripts and generate with --3ds --switch --generate. The native project retains the Tandem app and scheme.

03 / Sign, run, and verify

Choose your signing team and a physical arm64 iPhone or iPad. Start the development build through Xcode. Switch emulation requires debugger/JIT state and a successful native dual-mapping check; ordinary signing alone does not provide JIT.

The 3DS adapter uses the CPU interpreter when debugger/JIT state is unavailable. Interpreter performance has not been measured. Switch gameplay is rejected in the simulator.

A successful build is a milestone, not a compatibility result. Check rendering, audio, input, saves, pause/resume, and memory use on the physical device before sharing a playable-release claim.

Your files stay yours.

Use the library’s + button to import supported game files from Files. Tandem copies the selected file into its library and preserves the source. An accepted extension does not prove that a game can boot; the native core decides that.

  • 3DS: .3ds, .cci, .cxi, and .3dsx. CIA packages are not direct-boot imports.
  • Switch: .nro, .nso, .xci, and .nsp.

Import your Switch prod.keys in Settings. When the Switch core is embedded, Settings can install your firmware ZIP and reports completion after the native installer finishes. The core validates the actual key contents.

3DS user data belongs in the core’s standard subdirectories under Tandem/System/3DS in the app’s Documents directory. Switch keys, logs, cache, saves, and firmware use its own root under Tandem/System/Switch.

No ROMs, keys, or firmware are included or downloaded by this project. Use your own games and required console data.

What is verified?

23 library and key import tests + 4 simulator tests passed

All 23 Foundation-only EmulationKit tests pass on macOS, covering file import, persistence, rollback, path validation, and recovery. The iOS interface compiles, and all 4 session-lifecycle tests execute in the iOS simulator with 0 failures in macOS CI. Those session tests use an injected core; they do not run the native emulator cores or establish gameplay compatibility.

swift test --package-path Packages/EmulationKit

To execute the interface and lifecycle tests, use macOS and an installed iOS simulator:

xcodegen generate
xcodebuild -project Tandem.xcodeproj -scheme Tandem \
  -destination 'platform=iOS Simulator,name=iPhone 17' test

Choose a simulator actually installed on your Mac. The native archive and IPA build also passed in macOS CI. All 21 packaged Mach-O images have deployment minimums at or below iOS 17, and the bundled dependency-closure check passed. Signing, firmware installation, device JIT, graphics, audio, saving, game compatibility, performance, and memory limits remain unverified on a physical device.

Shared work. Shared credit.

Tandem’s new source uses AGPL-3.0-or-later. The native dependencies retain their own licenses and source notices.

  • Cytrus supplies the iOS 3DS core, built on Azahar/Citra; its GPL notices apply.
  • Folium supplies the pinned source structure and dependency artifacts.
  • MeloNX supplies the Switch NativeAOT port; the pinned fork declares AGPLv3-or-later and records its Ryujinx lineage.
  • MoltenVK, SDL, FFmpeg, Boost, zstd, and transitive dependencies each retain their own notices.

Preserve the relevant notices, corresponding source, patches, and build scripts when distributing a native build. Nintendo 3DS and Nintendo Switch are Nintendo trademarks; this is an independent project.
