# Player customization

Open the layout button in the player toolbar. The game pauses while you edit settings. Close the menu and resume when ready.

Portrait and landscape settings are saved independently. Select the orientation you want to edit, then choose Stacked, Side by side, or Top screen focus. Adjust the overall screen size and the gap between screens. Both screens retain their native aspect ratios.

Touch controls can be resized, faded, or hidden for controller use. The left, right, and menu controls move as groups. Drag their handles in the preview or use the horizontal and vertical sliders. Positions are relative to the player area; controls are kept within the available edges. Depending on the chosen position, controls may overlap the game screens. The toolbar remains visible so you can restore hidden controls.

Reset this orientation returns only the selected orientation to its defaults. No game files, save states, or controller bindings are changed. The rendering layers remain the same objects when changing layouts or rotating the device.

## Device testing

Check every preset in both orientations during gameplay, then adjust size and gap. Verify that the bottom screen's touch input still maps correctly, the game continues after closing the menu, and the layout survives closing and reopening the app. Move control groups to each edge, change size and opacity, and test hiding/restoring controls with a physical controller.
